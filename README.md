# PFO1 - Portfolio Personal

## Descripción
Landing page de portfolio personal para el curso de Desarrollo Front End.

## URL de Vercel
https://pfo1-portfolio-git-main-elianavarro.vercel.app/

## Decisiones de diseño
- **Paleta de colores**: Usé morado (#6C63FF) como color principal porque transmite creatividad y profesionalismo.
- **Fuente**: Elegí Inter por su legibilidad y versatilidad.
- **Grid vs Flexbox**: Usé Grid para estructuras complejas (sección de habilidades) y Flexbox para alineaciones simples (header y navegación).
- **Modo oscuro**: Opté por fondo oscuro para destacar elementos y crear un ambiente moderno.
